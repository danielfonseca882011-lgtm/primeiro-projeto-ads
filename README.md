

\# 💰 Controle Financeiro



Projeto desenvolvido por Daniel Fonseca, estudante de Análise e Desenvolvimento de Sistemas (ADS).



\## Sobre o projeto



Sistema de controle financeiro desenvolvido em Python com interface web utilizando Streamlit.



O objetivo é permitir o gerenciamento de receitas, despesas e saldo financeiro de maneira simples e intuitiva.



\## Funcionalidades



\- Adicionar receitas

\- Adicionar despesas

\- Consultar saldo

\- Visualizar resumo financeiro

\- Gráfico de receitas e despesas



\## Tecnologias utilizadas



\- Python

\- Streamlit

\- Git

\- GitHub



\## Acesse o site



https://controle-financeiro-daniel.streamlit.app



\## Como executar



Instale as dependências:



pip install -r requirements.txt



Execute o aplicativo:



streamlit run app.py
